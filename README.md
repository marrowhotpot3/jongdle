# 작들 (雀들)

마작 역(役) 하나를 완성하는 대표 손패 14장을 정답으로 놓고, 색으로 힌트를 받으며
맞혀나가는 웹 게임이에요. 

- **데일리 모드**: 매일 한국시간(KST) 자정에 바뀌는 오늘의 역 문제 (하루 1문제, 결과는 브라우저에 저장)
- **무한 모드**: 언제든 새 역으로 다시 도전

- **패 버튼(역키보드)**: 역 목록 아래에서 패를 하나씩 눌러 손패 14장을 채움 (자동 정렬). 패 자체는
  기본적으로 색으로 힌트를 주지 않지만, 역을 전부 맞히고 나면 아래 "패 직접 맞추기 모드"에 따라
  색이 붙기 시작해요.
- **역 목록**: 마작 역 28종을 항상 나열해두고, 처음엔 전부 회색이에요(목록 위의 "역 목록" 글자
  라벨은 없고, 색 범례만 붙어 있어요). 제출(시도 1회 소모)한 손패가 **정답 손패와 실제로 겹치는
  역**을 발견할 때마다 그 역만 색이 바뀌어요 — 초록은 정답이 실제로 성립시키는 바로 그 역, 주황은
  정답과 연관은 있지만(예: 혼일색↔청일색, 찬타↔준찬타, 역패 백ㆍ발ㆍ중↔소삼원ㆍ대삼원) 상위 역에
  밀리거나 별도 역이라 정답에서는 따로 점수가 매겨지지 않는 역이에요. 온스크린 키보드처럼
  한 번 발견한 색은 계속 남아요. 제출해서 실제로 성립시켰지만 정답과는 무관한 역은, 아직 한 번도
  성립시켜본 적 없는 역(테두리만 있는 연한 회색)과 구분되도록 진한 회색 배경으로 채워져요(발견한
  글자가 계속 남는 키보드의 회색/탈락 표시와 같은 개념).
- **제출 전 자가 확인 팝업**: 손패 14장을 다 채우면 입력칸 아래에 "이 손패로 성립하는 역" 팝업이
  떠요. — 성립하는 역이 하나도 없으면 팝업에 "성립하는 역이 없어요"
  라고 뜨고, 제출 버튼도 회색 바탕에 붉은 글씨 "화료 불가"로 바뀌며 비활성화됨) 다만 **이미 과거
  제출로 밝혀진 역**이 지금 손패에도 나타나면, 이미 합법적으로 공개된 정보라 팝업에서도 역 목록과
  같은 초록/주황/회색(정답과 무관하다고 밝혀진 역) 색을 그대로 보여줘요. 손패 14장을 다 채우면
  같은 팝업에 **"화료 시 점수"**도 함께 떠요
- 제출한 손패는 역 목록/패 버튼 아래에 **최신순(가장 최근 제출이 맨 위)** 으로 기록되고, 그 시도에서
  실제로 성립시킨 역이 전부 나열돼요 — 정답과 겹치는 역만 초록/주황으로 강조되고
  나머지는 회색이에요. 각 기록 왼쪽 위 바깥의 작은 번호 배지로 몇 번째 시도인지 알 수 있어요.
  손패 아래에는 **화료 시 총점** 한 줄이 표시돼요 — 그 시도의 손패로 실제 마작을 플레이했을 때 오야가
  받는 점수(개별 역 점수를 따로 더하지 않고, 판수를 전부 합쳐 점수표에서 한 번에 찾는 실제 채점
  방식이고, 손패에 도라 패가 있으면 1장당 1판씩 더해짐 — 역만은 예외)이고, 정답 손패의 총점보다
  높은지(▼)ㆍ낮은지(▲)ㆍ같은지(＝)도 함께 알려줘요.
  만관 이상의 점수는 숫자 대신 **만관ㆍ하네만ㆍ배만ㆍ삼배만ㆍ역만ㆍ더블역만**
  같은 실제 마작 용어로 표기되고, 역만급 역이 여러 개 겹쳐 48000의 3배 이상이 되는 점수도
  **"세 배 역만"ㆍ"네 배 역만"ㆍ"여섯 배 역만"**처럼 순우리말 배수 이름으로 표기돼요. 이름이 없는
  1~4판(1,500~11,600점)은 숫자 그대로 보여줘요. 승리 조건 자체는 여전히 "정답 손패 14장을 그대로
  맞히기"예요. 총 **10번**의 시도 안에 맞혀야 해요.
- **타일 힌트**: 어떤 제출에서 잘못 포함된 역 없이 정답 손패가 성립시키는 역을 전부 맞히면, 그
  시도부터는 제출 기록의 패에도 초록(정답 손패에 포함된 패)ㆍ회색(포함되지 않은 패) 색이 나타나요.
- **패 직접 맞추기 모드**: 타일 힌트가 한 번 해금되면, 그 뒤로 쌓이는 제출 기록들을 근거로 화면
  아래 패 버튼(역키보드)의 패에도 색이 들어가기 시작해요. 초록은 정답에 **있다고 확인된** 패, 회색은
  정답에 **전혀 없다**고 확인된 패예요(역키보드는 초록/회색 두 상태만 써요). 어떤 제출에서 그 패를
  정답보다 많이 넣어봐서 초과분이 드러나면 그 순간 정확한 개수까지 확정되고, **어떤 시도 하나가
  정답 손패와 통째로 똑같아지면**(그 시도로 정답 14장 전체를 이미 다 알아낸 셈이므로) 초과로 더
  내본 적이 없어도 정답에 포함된 패는 전부 즉시 초록, 나머지는 즉시 회색으로 확정돼요. 아직 한 번도
  실마리가 없는 패는 색이 붙지 않아요.
- **도라**: 새 문제(데일리ㆍ무한 모드 모두)를 시작할 때마다 34종의 패 중 1~4개가 완전히 랜덤으로
  도라로 정해져요. 역키보드와 이미 제출된 손패의 해당 패 위로 흰 하이라이트가 재생돼요.
  도라는 정답 손패와는 전혀 무관하게 순수 랜덤으로 뽑히지만, **화료 시 총점 계산에는 실제로
  반영돼요** — 손패에 도라 패가 있으면 1장당 1판씩(같은 도라 패를 여러 장 들고 있으면 그만큼
  전부) 더해져요. 역만 점수는 실제 마작 규칙대로 도라 영향을 받지 않아요.
  데일리 모드는 하루 동안(새로고침해도) 같은 도라가 유지돼요.
- **게임이 끝나면(성공/실패 모두) 정답 손패 14장을 별도의 팝업 창으로 공개**해요.
  팝업 맨 위에는 **"🎉 성공!"** 또는 **"😵 실패 (10회 모두 소진)"**이 색과 함께 크게 표시돼서 결과를
  한눈에 알 수 있고, 그 아래 정답 손패와 "결과 공유하기"/"다음 문제" 버튼이 있어요.
  팝업을 닫아도 시도 표시 배지 옆의 "결과 보기" 배지 자체가 초록
  (성공)ㆍ빨강(실패)으로 물들며 문구도 함께 바뀌어서, 팝업을 다시 열지 않아도 결과를 알 수 있어요.
- **결과 공유하기**: 시도별 결과를 🟩(성립)ㆍ🟨(연관)ㆍ⬛(무관) 이모지 그리드 텍스트로 만들어
  클립보드에 복사해요(게임이 끝난 뒤에만 가능). 
- **X에 공유하기**: "결과 공유하기" 바로 옆 버튼으로, 같은 이모지 그리드 텍스트를 미리 채운
  X(트위터) 글쓰기 화면을 새 탭으로 열어줘요. 
- **역 이름에 마우스를 올리면(모바일은 길게 누르면)** 판수ㆍ간단한 설명이
  담긴 툴팁이 떠요. 역 목록ㆍ자가 확인 팝업ㆍ제출 기록 어디서든 동작해요.
- **처음 접속하면 게임 방법 팝업이 자동으로 떠요.** 한 번 보면 다음 방문부터는
  자동으로 뜨지 않고, "?" 버튼으로 언제든 다시 볼 수 있어요.
- 패를 하나만 지우고 싶으면 별도 버튼 없이 입력칸에 놓인 그 패를 직접 눌러서 뺄 수 있고, 손패를 전부 지우려면
  "전체 지우기"를 써요.
- 라이트/다크 테마 자동 대응 + 수동 전환

리치·일발·멘젠쯔모·하이테이처럼 **상황에 따라 성립하는 역**은 손패만으로 재현할 수 없어서 제외했고,
탕야오·청일색·국사무쌍처럼 **패 모양만으로 성립이 정해지는 역** 28종만 출제돼요.

```

│   ├── data.js          # 역 28종 + 대표 손패 데이터, 정렬 유틸

│   ├── yakuEngine.js     # 실제 마작 규칙 기반 역 판정 엔진 (분해·역 체커·상위 역 대체·화료 가능 여부)
│   ├── tileArt.js         # 마작패 문양 SVG 생성 (통/삭/만/자패)
│   └── app.js            # 화면 렌더링과 이벤트 처리 (역 목록의 정답 겹침 판정 포함)
├── test/
│   ├── logic.test.js     # 데이터/로직 단위 테스트 (Node만 있으면 실행 가능)
│   ├── yakuEngine.test.js # 역 판정 엔진 단위 테스트
│   └── e2e.test.js        # Playwright 브라우저 스모크 테스트 (선택)
└── CHANGELOG.md         # 버전별 변경 기록 (다운로드 zip 파일명의 버전과 대응)
```

## 로컬에서 실행해보기

빌드 과정이 없어서 정적 파일 서버 하나면 충분해요.

```bash
cd jongdle
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 VS Code의 "Live Server" 확장, `npx serve` 등 원하는 정적 서버를 사용해도 돼요.

### 로직 테스트 실행

```bash
node test/logic.test.js
node test/yakuEngine.test.js
```

Playwright가 설치되어 있다면 브라우저 동작까지 확인하는 e2e 테스트도 돌릴 수 있어요 (먼저 위 정적 서버를
`8123` 포트로 띄운 상태여야 해요. `test/e2e.test.js` 상단의 `BASE_URL`을 필요하면 수정하세요).

```bash
npm install -D playwright
python3 -m http.server 8123 &
node test/e2e.test.js
```

## 역(役) 추가·수정하기

모든 문제 데이터는 `js/data.js`의 `YAKU_LIST` 배열 하나에 들어 있어요. 각 항목은:

```js
{
  id: "tanyao",          // 고유 id
  name: "탕야오",         // 화면에 표시할 한글 이름
  hanja: "断幺九",        // 한자 표기 (지금은 화면에 노출하지 않음, 데이터로만 보관)
  category: "일반역",     // "일반역" | "역만"
  han: "1판",             // 판수 설명 텍스트
  hanValue: 1,            // 점수 계산용 숫자 판수 (역만은 생략, category로 처리)
  desc: "...",            // 한 줄 설명
  tiles: ["2m","3m", ...] // 정답 손패 14장 (순서 무관, 항상 자동 정렬해서 비교함)
}
```

- 패 표기: `1m`~`9m`(만/캐릭터), `1p`~`9p`(통/서클), `1s`~`9s`(삭/뱀부), `1z`~`7z`(자패: 동남서북백발중)
- 새 역을 추가하면 `node test/logic.test.js`를 실행해서 손패가 14장인지, 같은 종류 패가 4장을 넘지 않는지,
  다른 역과 정답 손패가 겹치지 않는지 자동으로 검증해줘요.
- 새 역을 추가했다면 `js/yakuEngine.js`의 `CHECKERS`에도 그 역을 실제로 판정하는 함수를 추가해야
  제출 후 결과에 반영돼요. `혼일색→청일색`처럼 상위 역이 성립하면 하위 역을 표시에서 제외하는 관계가
  있다면 `FAMILIES` 배열에 `[하위 역 id, 상위 역 id]` 쌍을 추가하세요 (`resolveDisplayYaku`가 자동으로
  하위 역을 결과에서 제거해요). `node test/yakuEngine.test.js`로 검증하세요.
